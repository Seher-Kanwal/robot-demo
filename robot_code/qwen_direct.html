Each camera image goes straight to Qwen3-VL, which has to locate (box) and name every object by itself. There's no detector and no OOD split. Module 2's pipeline is paused while this runs, so Qwen gets the GPU to itself. One pass takes a few seconds, so the result updates every few seconds while the small camera view stays live.
