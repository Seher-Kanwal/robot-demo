Ask & Remember

Module 3 · Qwen3-VL direct–

      

      
The whole camera image goes to Qwen3-VL, which locates and names every object by itself: no detector, no OOD split.
        It runs inside Module 2's server (same Qwen weights, so no extra GPU memory). Module 2's pipeline pauses while it runs.
        Each pass takes a few seconds.

      
Start uses Module 2's threshold settings if it has to start the server.
