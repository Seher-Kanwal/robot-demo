Part 3 · OOD + Memory + OED

Memory first, the VLM only for what's new

connecting… camera –

Each camera frame goes through three steps. 1 · OOD detection: the detector and its energy score split the boxes into known classes and out-of-distribution (OOD) objects. 2 · Memory: every OOD box is compared with the objects the robot was taught in Part 1. A match names it, and the VLM is never asked. 3 · OED with the VLM: only the OOD boxes that memory can't name go to Qwen3-VL, which names them open-ended. Box numbers (#1, #2, …) are the same on every image below.
